# Personal Agent Platform

本地运行的个人多 Agent 开发平台。用自然语言描述目标，AI 生成可视化工作流，经你审批后由开发者 Agent 执行、审查 Agent 把关，并支持持续迭代。

## 技术栈

- Nuxt 4 + TypeScript
- Tailwind CSS 4 + DaisyUI 5
- Vue Flow（工作流画布）
- SQLite + Drizzle ORM
- Claude Agent SDK（Agent 运行时）

## 快速开始

```bash
pnpm install
pnpm dev
```

打开 http://localhost:3000
